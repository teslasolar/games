# 🎮 Konomi Games - 3D Interactive Gallery

A collection of interactive Three.js experiences and games that run entirely in the browser. Perfect for GitHub Pages!

## 🌟 Features

- **8 Interactive Experiences**: From simple cube spinners to complete 3D operating systems
- **Pure JavaScript**: No build process required - just HTML, CSS, and Three.js
- **GitHub Pages Ready**: Automatically loads all games from .md files
- **Responsive Design**: Works on desktop and mobile browsers
- **Real-time 3D**: Powered by Three.js WebGL rendering

## 🎯 Games & Demos

### 🎲 Cube Spinner
Interactive rotating cube with mouse control and color animations.

### ✨ Particle Storm
Interactive particle system with 5000+ particles and multiple interaction modes.

### 🚀 Space Shooter
Classic space shooter in 3D with enemies, scoring, and multiple levels.

### 🏔️ Terrain Explorer
Navigate procedurally generated 3D terrain with flying camera controls.

### 🧠 Neural Network Visualizer
Watch a neural network train in real-time with 3D visualization.

### 🧱 Block Breaker 3D
Classic brick breaker game reimagined in 3D with particle effects.

### 🌀 Fractal Explorer
Explore infinite fractal patterns including Sierpinski, Menger Sponge, Koch Snowflake, and Mandelbrot Set.

### 🖥️ Konomi OS
A complete 3D operating system with floating windows and AI integration.

## 🚀 Quick Start

### View Online
Simply open `index.html` in your browser or deploy to GitHub Pages.

### Local Development
```bash
# Clone and serve
git clone https://github.com/YOUR_USERNAME/games.git
cd games
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## 🎮 Controls

- **Arrow Keys**: Navigation (varies by game)
- **Mouse**: Rotate camera / Look around
- **Space**: Action button
- **R**: Restart / Reset
- See each game for specific controls

## 🛠️ Technical Details

- **Three.js r128**: 3D rendering
- **Vanilla JavaScript**: No frameworks
- **HTML5 Canvas**: UI rendering
- **60 FPS** target performance
